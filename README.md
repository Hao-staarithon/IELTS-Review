# 雅思复盘台 · 0.1

一个在 Windows 的 Chrome / Edge 中使用的小应用：今日总览、每日复盘、剑雅成绩、ChatGPT 项目自动归档。

## 第一次使用

1. 保留整个 ielts-desk 文件夹，放在固定位置。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启页面里的「开发者模式」，点击「加载已解压的扩展程序」，选择本文件夹里的 **extension** 文件夹（包含 manifest.json 的那层）。
4. 打开或刷新 `https://chatgpt.com/` 并保持登录。复盘台「同步与设置」已经预填本次雅思项目 ID；请与项目地址核对。
5. 等待状态变成「已同步」，检查「已归档的项目聊天」是否列出你的实际聊天。点击浏览器扩展图标即可再次打开复盘台。

也可以先打开 `START-HERE.html` 看图文说明，或打开 `extension/index.html` 试用界面。独立试用与扩展使用不同的数据存储；需要搬运试用数据时，使用「导出全部备份 / 导入备份」。

## 日常怎么用

- 浏览器保持运行，并保留一个已登录的 ChatGPT 标签页（可以在后台）。默认每 2 分钟检查「雅思」项目。
- 复盘台页面不必一直开着。电脑休眠、浏览器关闭、登录失效时不会继续同步；重新打开后会尝试补齐。
- 同步从项目列表读取聊天，不要求逐个打开项目里的每段对话。其他设备上产生的更新，需先在 ChatGPT 服务端可见，随后由电脑上的组件读取。
- 如 ChatGPT 的网页接口变化，界面会报告失败并保留已有记录，不会假装成功或清空数据。
- 此版本只整理文字消息；图片、录音和附件内容没有自动识别。

## 已实现

### 今日总览

按上午 / 下午 / 晚上 / 随时安排定量任务。完成量可以只填一部分。阅读做题和复盘是不同任务。新闻听力默认 20 分钟。初始计划数量是可调整的建议，并非从完整历史中已确认的安排。

「安排明天」保留可调整的建议量，把昨日余量优先包含在目标内，避免机械地天天叠加。计划不会覆盖已有日期的任务。完成百分比是各项任务完成比例的平均值，不会把单词数与分钟数直接相加。

### 每日复盘

同时记录执行情况、学习问题与下一步调整。聊天按原消息日期（上海时区）自动归档，保留原话和来源链接，助手给出的建议不会被当成已执行。

第一版采用本地规则整理，**没有另接 AI 自动改写长篇复盘，也没有全面理解任意口语表述的能力**。明确数量可以自动更新；复杂情况可从原话回看和补写。

可识别的例子：

- `今天背了150个单词` → 当天词汇累计 150。
- `我又背了50个单词` → 明确新增 50。
- `今天总共背了210个单词` → 当天累计更新到 210。
- `新闻听了20分钟` → 当天新闻听力累计 20。
- `首次限时完成，剑雅19 Test1 阅读28/40` → 成绩入库并记录明确的练习条件。

`明天背300个`、`我还没背150个` 等不会当成已完成。若有多个同类型任务，自动累计只写到当天第一个同类任务，以免重复计算。你后来手动修正的进度不会被旧消息覆盖。

### 剑雅成绩

支持整套、单篇、分部分正确数、用时、首次 / 重做、限时条件和学习备注。

听读参考水平取最近最多 5 套首次、限时、无辅助的整套练习的中位数，已注明的同一套题去重；显示样本量和波动。分数换算是参考表，不同试卷分数线可能略有差异。中位数可能为 6.25 等统计值，不等于正式考试单科成绩。

写作、口语录入老师或模考评分后，可以显示四科综合练习参考；缺科时显示空缺。写口采用最新一条记录并注明日期。它不是对正式考试的保证。

官方依据：

- https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail
- https://ielts.idp.com/egypt/results/scores/reading

## 数据与权限

数据保存在当前浏览器的扩展本地存储中。没有云服务器、统计追踪、付费 AI 接口调用，不会把聊天发送给本应用开发者。

浏览器会要求访问 `chatgpt.com`。同步组件使用当前已登录网页的会话，只发读取请求；会话凭据仅在网页内存中使用，不写入复盘台或备份。它使用非官方公开承诺的网页内部接口，因此不能保证长期兼容。

卸载扩展、清除扩展数据或更换浏览器前，请在设置里导出备份。备份包含已归档的聊天。导入备份会替换当前数据。扩展文件夹不要在使用期间删除；更新前也请先备份。
